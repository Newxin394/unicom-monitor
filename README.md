# 联通余量查询与跳点监控 (ChinaUnicom Quota & Traffic Jump Monitor)
纯AI 无手写有问题，不会修
> 🚀 **轻量、极速、无混淆、支持三色跳点精准预警、双独立通道冷却与全平台推送的中国联通余量监控**。完美兼容 **呆呆面板 (Dumb-Panel)**、**青龙面板 (QingLong)** 以及 **OpenWrt 路由器** 裸机运行。

---

## ✨ 核心特性

- ⚡ **双版本驱动**：
  - **Go 工业级终极版 (`main.go` / `10010v4x`)**：单静态二进制，0 外部依赖，内存占用仅 4MB，执行时间 < 0.5 秒；自带 Telegram 守护进程与文件排他锁。
  - **Node.js 精简版 (`index.js`)**：无混淆轻量脚本，适合快速调试与开箱即用。
- 🚦 **三色动态状态前缀**（通知栏 & 消息置顶识别）：
  - 🔴 **`[跳点]`**：**仅通用流量跳点达标**（发生漏流 / 需排查分流规则，标红醒目警报）；
  - 🟢 **`[免流]`**：**仅定向免流跳点达标**（正常免流消耗，绿标代表安全放心）；
  - 🟡 **`[混合]`**：**通用与免流同时达标**（混合跳点预警）。
- 🔒 **双独立通道冷却（彻底解耦）**：
  - 通用跳点与免流跳点各自拥有独立的冷却计时器（`LastAlertNorm` / `LastAlertFree`）。
  - 解决“免流看视频频繁跳点触发冷却，把关键的通用漏流警报吞掉”的行业顽疾！
- 🛡️ **生产级容灾与防抖**：
  - **接口突发归零防抖**：遇到联通网关半夜维护返回 0 时，自动放弃覆盖基线，防止后续造成几十 G 误报。
  - **原子落盘与自愈**：通过 `flock` 文件排他锁保证并发安全，每次写盘自动保留健康的 `.bak`，主数据异常秒级自愈。
  - **显式钉死东八区（CST）**：彻底解决容器 UTC 时区导致早上 8 点才清零今日用量的 Bug。
  - **`config.sh` 自动读取**：Go 内核与 Shell 启动脚本双重自动读取面板 `config.sh` 中的环境变量，无需手动导入。
- 💬 **交互式 Telegram Bot**：
  - 支持 `/start`、`/check`、手机底部专属快捷键盘与卡片内联 `[ 🔄 刷新跳点 ]` 按钮，随点随查。
  - 自带 409 Conflict 智能避让，遇到重复实例自动休眠避让，不打满 CPU。
- 🔔 **多通道推送规范支持**：
  - **Telegram 机器人**（支持反代 API Host、HTML 富文本高亮排版）。
  - **钉钉机器人**（严格实现 HMAC-SHA256、Base64 与 URL 编码规范加签，杜绝 310000 报错）。
  - **微信 PushPlus**、**Bark** 及青龙/呆呆标准通知渠道。

## 📦 环境变量说明

直接在面板的 **【环境变量】** 或 **`config.sh`** 中配置即可，程序会自动解析：

| 变量名 | 说明 | 必填 | 默认值 / 示例 |
| :--- | :--- | :---: | :--- |
| `UNICOM_COOKIE` | 联通手机营业厅抓取的完整 Cookie（支持多账号换行） | **是** | `acw_tc=...; c_id=...;` |
| `ChinaUnicom_10010v4_min_usage` | **自动通用跳点**报警阈值 (MB)，0 为关闭 | 否 | `50` |
| `ChinaUnicom_10010v4_min_free_usage` | **自动免流跳点**报警阈值 (MB)，0 为关闭 | 否 | `400` |
| `ChinaUnicom_10010v4_cooldown` | 通用跳点报警冷却时间（秒） | 否 | `0` (不限制) |
| `ChinaUnicom_10010v4_free_cooldown` | 免流跳点报警冷却时间（秒） | 否 | `1800` (30分钟) |
| `ChinaUnicom_10010v4_bot_minutes` | **机器人主动查询**默认对比时长（分钟） | 否 | `30` (默认对比 30 分钟前) |
| `AUTO_CHECK_INTERVAL_MIN` | 守护进程**后台回环检测**周期（分钟） | 否 | `5` (每 5 分钟自动循环检测) |
| `TG_BOT_TOKEN` | Telegram Bot Token | 否 | `7014392040:AAF4...` |
| `TG_USER_ID` | Telegram 接收者 User ID | 否 | `1033435406` |
| `TG_API_HOST` | Telegram API 反代地址（国内服务器推荐） | 否 | `https://api.telegram.org` |
| `DD_BOT_TOKEN` | 钉钉机器人 Webhook 中的 `access_token` | 否 | `0302c0d50b6...` |
| `DD_BOT_SECRET` | 钉钉机器人安全设置中的【加签】Secret | 否 | `SECb38f089...` |

> 💬 **Telegram 机器人与回环检测特性**：
> - **后台回环巡检**：守护进程后台默认每 5 分钟自动执行一次回环检测，向 24 小时历史时间线持续注入快照并触发跳点告警；
> - **菜单指令**：`⚡ 实时跳点`（对比上次巡检）、`🔍 查询跳点`（默认对比 30 分钟前）、`📦 套餐总余量`；
> - **自定义时长**：支持输入 `/check 10`、`/check 30` 或直接发送 `10分钟` 回溯任意时长；
> - **卡片内联切换**：卡片下方支持一键点击 `[ ⏱ 3分钟 ]`、`[ ⏱ 5分钟 ]`、`[ ⏱ 10分钟 ]`、`[ ⏱ 30分钟 ]` 秒级切换。

## 🚀 部署与使用

### 方式 A：使用 Go 极速版（推荐，0 依赖、资源占用极低）

1. **获取预编译产物**：
   可以直接使用仓库提供的 Linux ARM64 编译二进制 `10010v4x`，或者自行编译：
   ```bash
   # 交叉编译 Linux ARM64（适用于大多数 OpenWrt 路由器、NAS、群晖）
   CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -ldflags="-s -w" -trimpath -o 10010v4x main.go
   ```
2. **面板任务命令**：
   - **呆呆面板 / 青龙面板**：
     ```bash
     task 10010v4x.sh
     ```
   - **定时规则**：`*/3 * * * *` (推荐每 3 分钟检测一次)。

### 方式 B：使用 Node.js 版

- **面板任务命令**：`task index.js` 或 `node index.js`
- **定时规则**：`*/3 * * * *`
