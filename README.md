# 联通余量查询与跳点监控 (ChinaUnicom Quota & Traffic Jump Monitor)

> 🚀 **轻量、极速、无混淆、支持三色跳点精准预警、双独立通道冷却与全平台推送的中国联通余量监控**。完美兼容 **呆呆面板 (Dumb-Panel)**、**青龙面板 (QingLong)** 以及 **OpenWrt 路由器** 裸机运行。

---

## ✨ 核心特性

- ⚡ **双版本驱动**：
  - **Go 工业级终极版 (`main.go` / `10010v4x`)**：单静态二进制，0 外部依赖，内存占用仅 4MB，执行时间 < 0.5 秒；自带 Telegram 守护进程与文件排他锁。
  - **Node.js 精简版 (`legacy/index.js`)**：无混淆轻量脚本，适合快速调试与开箱即用。
- 🚦 **三色动态状态前缀**（通知栏 & 消息置顶识别）：
  - 🔴 **`[跳点]`**：**仅通用流量跳点达标**（发生漏流 / 需排查分流规则，标红醒目警报）；
  - 🟢 **`[免流]`**：**仅定向免流跳点达标**（正常免流消耗，绿标代表安全放心）；
  - 🟡 **`[混合]`**：**通用与免流同时达标**（混合跳点预警）。
- 🔒 **双独立通道冷却（彻底解耦）**：
  - 通用跳点与免流跳点各自拥有独立的冷却计时器（`LastAlertNorm` / `LastAlertFree`）。
  - 解决“免流看视频频繁跳点触发冷却，把关键的通用漏流警报吞掉”的行业顽疾！
- 🛡️ **生产级容灾与防抖**：
  - **接口突发归零防抖**：遇到联通网关半夜维护返回 0 时，自动放弃覆盖基线，防止后续造成误报。
  - **原子落盘与自愈**：通过 `flock` 文件排他锁保证并发安全，每次写盘自动保留健康的 `.bak`，主数据异常秒级自愈。
  - **显式钉死东八区（CST）**：彻底解决容器 UTC 时区导致早上 8 点才清零今日用量的 Bug。
  - **`config.sh` 自动读取**：Go 内核与 Shell 启动脚本双重自动读取面板 `config.sh` 中的环境变量，无需手动导入。
- 💬 **交互式 Telegram Bot**：
  - 支持 `/start`、`/check`、手机底部专属快捷键盘与卡片内联 `[ 🔄 刷新跳点 ]` 按钮，随点随查。
  - 自带 409 Conflict 智能避让，遇到重复实例自动休眠避让，不打满 CPU。
- 🔔 **多通道推送规范支持**：
  - **Telegram 机器人**（支持反代 API Host、HTML 富文本高亮排版）。
  - **钉钉机器人**（严格实现 HMAC-SHA256、Base64 与 URL 编码规范加签，杜绝 310000 报错）。
  - **微信 PushPlus**、**Bark** 及青龙/呆呆标准通知渠道。

## 📦 环境变量说明

直接在面板的 **【环境变量】** 或 **`config.sh`** 中配置即可，程序会自动解析：

| 变量名 | 说明 | 必填 | 默认值 / 随机示例 |
| :--- | :--- | :---: | :--- |
| `UNICOM_COOKIE` | 联通手机营业厅抓取的完整 Cookie（支持多账号换行） | **是** | `acw_tc=...; c_id=...;` |
| `ChinaUnicom_10010v4_token_online` | **TokenOnline 自动登录令牌**（联通 APP 抓包 `token_online`，Cookie 失效时自动换新，多账号换行对齐） | 否 | `8d575e92...` |
| `ChinaUnicom_10010v4_mobile` | 自动登录兜底用的**手机号**（配合服务密码走 RSA 密码登录） | 否 | `156xxxxxxxx` |
| `ChinaUnicom_10010v4_password` | 自动登录兜底用的**服务密码**（RSA 加密后提交 `login.htm`） | 否 | `******` |
| `ChinaUnicom_10010v4_min_usage` | **自动通用跳点**报警阈值 (MB)，0 为关闭 | 否 | `50` |
| `ChinaUnicom_10010v4_min_free_usage` | **自动免流跳点**报警阈值 (MB)，0 为关闭 | 否 | `400` |
| `ChinaUnicom_10010v4_cooldown` | 通用跳点报警冷却时间（秒） | 否 | `0` (不限制) |
| `ChinaUnicom_10010v4_free_cooldown` | 免流跳点报警冷却时间（秒） | 否 | `1800` (30分钟) |
| `ChinaUnicom_10010v4_bot_minutes` | **机器人主动查询**默认对比时长（分钟） | 否 | `30` (默认对比 30 分钟前) |
| `ChinaUnicom_10010v4_free_keywords` | 自定义**免流判定关键词**（逗号/顿号/竖线分隔，`flowType` 缺省时与默认关键词叠加生效，新套餐免改代码） | 否 | 留空 |
| `ChinaUnicom_10010v4_exclude_keywords` | **排除名单**关键词（逗号/顿号/竖线分隔，命中的明细如日租宝/赠款不参与任何统计） | 否 | 留空 |
| `ChinaUnicom_10010v4_normal_limited_only` | `1` = 通用阈值/速率/越级判定**仅统计"通用有限池"增量**（排除不限量池稀释与虚增，展示口径不变） | 否 | `0` |
| `ChinaUnicom_10010v4_history_hours` | 历史快照保留时长（小时，加大可支持更长 `/diff` 回溯，上限 720） | 否 | `24` |
| `ChinaUnicom_10010v4_debug` | `1` = 打印每条流量明细的 `flowType`/分桶结果（DEBUG-分流），用于校准分类规则 | 否 | `0` |
| `TG_BOT_TOKEN` | Telegram Bot Token | 否 | `1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ...` |
| `TG_USER_ID` | Telegram 接收者 User ID | 否 | `987654321` |
| `TG_API_HOST` | Telegram API 反代地址（国内服务器推荐） | 否 | `https://api.telegram.org` |
| `DD_BOT_TOKEN` | 钉钉机器人 Webhook 中的 `access_token` | 否 | `a1b2c3d4e5f67890a1b2c3d4e5f67890...` |
| `DD_BOT_SECRET` | 钉钉机器人安全设置中的【加签】Secret | 否 | `SEC1234567890abcdef1234567890...` |
| `ENABLE_DAIDAI_NOTIFY` | 强制开启呆呆面板原生通知推送（`1` 为开启） | 否 | `0` (默认未配专属 TG/钉钉时自动兜底启用) |
| `ENABLE_ONLINE_QUOTE` | 开启在线一言 API 获取随机语录（`1` 为开启，`0` 使用内置离线库） | 否 | `1` |
| `ChinaUnicom_10010v4_custom_quotes` | 自定义随机语录列表（支持换行或 `\|` 分隔） | 否 | 留空使用内置精选语录库 |

> 💬 **模版占位符与随机语录**：
> - 模版支持：`[随机语录]`、`[一言]`、`[语录]`、`[通用速率]`、`[免流速率]` 等丰富占位符；
> - **多渠道与面板推送机制（智能防冲突）**：
> - **专属通道优先**：配置了 `TG_BOT_TOKEN` 或 `DD_BOT_TOKEN` 时，优先通过专属 Bot 推送（TG 独享内联交互按钮与指令），避免消息重复轰炸；
> - **呆呆面板智能兜底**：若未配置专属 TG/钉钉，在呆呆面板（Dumb-Panel）环境下会自动通过面板通知网关推送，一键打通面板后台配置的 **22+ 种推送渠道**（Bark、企业微信、飞书等）；
> - **定时巡检与自愈**：由外部 Cron（推荐 3 分钟）统一驱动检测与告警，守护进程自动保活；
> - **菜单指令**：`⚡ 实时跳点`（对比上次巡检）、`🔍 查询跳点`（默认对比 30 分钟前）、`📦 套餐总余量`。

## 🚀 部署与使用

### 方式 A：使用 Go 极速版（推荐，0 依赖、资源占用极低）

1. **获取预编译产物**：
   可以直接使用仓库提供的 Linux ARM64 编译二进制 `10010v4x`，或者自行编译：
   ```bash
   # 交叉编译 Linux ARM64（适用于大多数 OpenWrt 路由器、NAS、群晖）
   CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -ldflags="-s -w" -trimpath -o 10010v4x main.go
   ```
2. **面板任务命令**：
   - **呆呆面板 / 青龙面板**：
     ```bash
     task 10010v4x.sh
     ```
   - **定时规则**：`0 */3 * * * *` (推荐每 3 分钟检测一次)。

### 方式 B：使用 Node.js 版（轻量脚本、适合快速调试）

1. **安装依赖**：
   ```bash
   npm install axios
   ```
2. **面板任务命令**：
   - **呆呆面板 / 青龙面板**：
     ```bash
     task legacy/index.js
     ```
     或直接运行：
     ```bash
     node legacy/index.js
     ```
   - **定时规则**：`0 */3 * * * *` (推荐每 3 分钟检测一次)。
